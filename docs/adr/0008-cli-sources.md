# ADR 0008 — CLI source loading

Status: Accepted.

Source policy and deb822 files are local operator-controlled inputs, not authenticated repository data. Open them through bounded, component-wise no-symlink traversal, validating owner and rejecting group/other-writable paths before parsing. List only enabled sources accepted under explicit policy; listing does not assert keyring readability, repository authenticity, freshness or package availability. Missing, unsafe or malformed inputs fail closed without partial output. CLI JSON responses and errors must have a versioned schema. Repository update and cached search must separately verify signed metadata and freshness; listing alone must not initialize cache or change system files.

The `sources list` command uses `--config` (default `/etc/dich/sources.toml`) and optional global `--json`. JSON success contains `schema_version: 1`, `status: completed` and a `sources` array whose entries are marked `configured`. JSON failures contain the same schema version, `status: error`, and an error object with a stable `code` and safe message. Listing does not validate the contents of the configured keyring. The package install path is separately restricted to ADR 0029's authenticated DSO profile subset; other package classes remain unsupported.

The library fetches `InRelease` over restricted HTTPS and verifies its signature before returning it. Only an HTTP 404 permits fetching `Release` and `Release.gpg`; both must then verify under the configured trust policy. Invalid signatures and other failures never trigger fallback. It can separately fetch a gzip/xz Packages index only for an explicitly time-validated Release and returns it only after checking its signed size and SHA256. Freshness must be checked again before use and cached publication still uses the source rollback floor. The CLI uses a 24-hour maximum Release age by default, overridable with `--max-age-seconds`; a signed `Valid-Until` is always enforced when present. When it is absent, the 24-hour signed `Date` limit applies; `--require-valid-until` rejects such repositories. This permits official Ubuntu archive metadata while retaining a bounded freeze window (ADR 0042). Update prefers a signed xz index, then gzip only when xz is absent from signed metadata. It publishes each entry separately, so a failed update may leave a partial cache. Offline queries reauthenticate Release and index data, reject missing or inconsistent components, and emit no partial results. Search matches lowercase package-name substrings; show and versions match exact names. Output includes name, version, architecture, source and suite, not full package descriptions, dependency plans or compatibility claims. Concurrent reads are not a global snapshot. JSON uses schema version 1.
