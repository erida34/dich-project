# ADR 0006 — Artifact identity and fetch boundary

Status: Accepted for the library-only artifact download slice.

Derive artifact identity only from a `VerifiedIndex` that retains the source policy used to authenticate its Release. Select an exact package name and version, require matching configured architecture or `all`, and reject duplicate matching records, unsafe relative paths, absent SHA256 or size, and excessive size. Paths are restricted to relative `pool/` `.deb` paths with no URL escapes or traversal. A selected record is metadata, not a downloaded, verified, extracted or installable package.

The library validates signed Origin, Suite/Codename, Date and Valid-Until against explicit operator maximum age, clock skew and whether Valid-Until is required. Omitting Valid-Until is permitted only under an explicit nonzero maximum age. Artifact authorization binds the selected record to the identical verified Release digest and source; the stream verifier checks freshness before and after reading and compares exact size and SHA256 before returning an anonymous temporary file. This assumes a trusted clock and does not yet persist anti-rollback state.

The transport uses ureq and rustls with the bundled WebPKI trust roots, HTTPS only, no environment proxy, no automatic redirects, and explicit timeout and byte limits. It follows at most five redirects only within the configured source's origin and base path, rejecting encoded, traversal, query, fragment and credential-bearing locations. It streams into temporary storage and compares exact size and SHA256 before returning a read-only API. DNS resolution may outlast the request timeout on platforms whose resolver cannot be interrupted. Cross-origin mirrors and proxies are currently unsupported. An isolated test on `dich-root` fetched a real Ubuntu `hello` artifact after verifying a cached signed Release and its Packages index; the deliberately long age policy used in that test is not production guidance.

Persisted rollback/freeze detection and durable cache publication remain unimplemented. Account for crash safety and concurrent cache updates in the subsequent cache milestone. No `fetch` CLI is wired yet, and verified download is not extraction, compatibility approval or installation.
